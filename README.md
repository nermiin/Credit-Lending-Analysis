# Credit & Lending Domain Analysis

End-to-end business analysis of **consumer lending** — from application and underwriting through disbursement and early-stage servicing.

## Purpose

Showcases BA deliverables for a personal loan product: credit policy translation, origination workflows, affordability assessment, and handoff to servicing systems.
