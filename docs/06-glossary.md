# Glossary — Lending

| Term | Definition |
|------|------------|
| **STP** | Straight-Through Processing — no manual underwriting |
| **APR** | Annual Percentage Rate — total cost of credit annualized |
| **PD** | Probability of Default — scorecard output band |
| **Adverse Action** | Regulatory notice explaining decline reasons |
| **Pull-through** | Approved applications that complete funding |
| **Counter-offer** | Alternative loan terms when original request fails policy |
| **SECCI / ESIS** | Pre-contractual credit information disclosures (EU) |
| **Disbursement** | Transfer of loan principal to customer account |
| **Underwriter** | Credit analyst reviewing non-STP applications |
